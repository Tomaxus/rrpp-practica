# Sala de Campaña RR. PP.

App para practicar planes de Relaciones Públicas: 5 casos (de fácil a complejo), objetivos SMART, matriz estratégica, cronograma y evaluación output/outcome/impacto, con Vocera, un coach IA (modo local o con Gemini al iniciar sesión, sin clave).

Abre `index.html` o visita la versión publicada en GitHub Pages.
